# Skillment Project Brief

## Project Overview
Skillment appears to be a multi-application platform with three main components:
1. Dashboard Application (Next.js)
2. Backend Service (Node.js/TypeScript)
3. Landing Page (Next.js)

## Core Requirements
- Multi-tenant organization-based system
- Authentication and authorization system
- Modern, responsive UI with dark theme
- Secure API communication between services

## Project Goals
- Create a seamless user experience for organization management
- Provide a scalable and maintainable codebase
- Implement secure authentication and data handling
- Support multiple organizations with isolated workspaces

## Technical Stack
- Frontend: Next.js with TypeScript
- Backend: Node.js with TypeScript
- Database: Prisma ORM
- Styling: Tailwind CSS
- Package Management: pnpm

## Project Scope
The project is structured as a monorepo with multiple applications:
- `/apps/dashboard`: Main dashboard application
- `/apps/backend`: Backend API service
- `/apps/landing`: Public landing page
- `/packages`: Shared packages and utilities

## Success Criteria
- Secure and reliable authentication system
- Smooth organization onboarding process
- Responsive and intuitive user interface
- Scalable backend architecture
- Comprehensive error handling
- Performance optimization
